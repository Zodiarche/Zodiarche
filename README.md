## Benjamin Guillemin

Développeur Fullstack Web & Mobile basé à Bordeaux.

Je conçois et développe des applications web, mobiles, desktop et des sites, de la conception au déploiement. Core Contributor & Community Lead sur l'écosystème open-source [Pokémon Workshop](https://github.com/PokemonWorkshop).

### Stack

**Langages** : TypeScript, JavaScript, Ruby, HTML, SCSS, SQL

**Frontend** : React, Next.js, React Native / Expo, TanStack (Query, Router, Start), Tailwind CSS, Zustand, Framer Motion

**Backend** : Node.js, NestJS, Fastify, Express, Prisma, PostgreSQL, MySQL, MongoDB

**Outils & DevOps** : Git, GitHub Actions, GitLab CI, Docker, Bun, Vite, Biome, Swagger / OpenAPI, Docusaurus, Postman, Figma, Excalidraw, Miro

**Testing** : Vitest, Jest, Testing Library, Supertest
